# API Contract

## Conventions
- JSON uses camelCase.
- Money is always integer cents (`10050` = $100.50).
- Account numbers and transaction IDs are strings.
- Timestamps are ISO 8601 UTC strings.
- Authenticated requests send `Authorization: Bearer <token>`.
- Errors return the `ApiError` shape: `{ code, message, field? }`.
- Usernames are generated by the server (first initial + last initial + 4 digits).

## POST /auth/register
**Request** (`RegisterRequest`)
```json
{ "firstName": "John", "lastName": "Doe", "email": "john@example.com", "password": "Secret123!" }
```
**201 Created** (`AuthResponse`)
```json
{
  "user": { "id": "u_1", "firstName": "John", "lastName": "Doe", "username": "jd4821", "email": "john@example.com" },
  "account": { "accountNumber": "1000004821", "balanceCents": 0, "userId": "u_1" },
  "token": "mock-token-u_1"
}
```
**409 Conflict**
```json
{ "code": "EMAIL_TAKEN", "message": "An account with this email already exists.", "field": "email" }
```
